# Reglas para futuros asistentes

- No usar frameworks sin autorizacion.
- No agregar React, Angular, Vue, Phaser ni librerias similares sin pedir confirmacion.
- No agregar backend.
- No agregar base de datos.
- No agregar dependencias externas innecesarias.
- Mantener JavaScript modular y separado por responsabilidades.
- Mantener la logica JavaScript fuera de `index.html`.
- Usar `localStorage` unicamente para guardar el mejor puntaje historico.
- Priorizar compatibilidad con PC y celular.
- Mantener el MVP simple antes de agregar mejoras visuales o nuevas mecanicas.
- Cargar assets localmente desde `assets/`.
- Documentar cambios relevantes en `README.md` cuando afecten uso, estructura o gameplay.
